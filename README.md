# 상담 스크립트 검색기 (화면)

슈피겐 CS 상담사용 검색기 **화면 코드만** 있는 곳이에요. 문안 · 공지 · 문의 자료는 여기에 없어요.

- 문안 · 관리자 공지: 비공개 저장소에서, 관리자에게 받은 **연결 코드**가 있는 PC만 읽어요.
- 요청시트 · 불량 모음 · 족보 공지 · 사진: 각 상담사 PC의 **‘슈피겐 CS 검색기 연결’ 확장**(상담기록기와 따로)이 그 PC에 로그인된 회사 구글 계정으로 읽어요.
- 연결 코드도 확장도 없는 사람이 이 주소를 열면 '연결 코드를 넣어 주세요' 화면만 보여요.
